# الجرس المدرسي الذكي V3 — مشروع Flutter/Dart + Android Kotlin

## الوظائف
- جدول الحصص: اسم الحصة، المادة، الصف، الشعبة، الوقت، أيام الأسبوع، تفعيل وتعطيل.
- العد التنازلي للحصة القادمة أثناء فتح التطبيق.
- حفظ الجدول والإعدادات محليًا.
- اختيار صوت من الجهاز، ونسخه إلى مساحة التطبيق، وتجربة الصوت.
- أجراس حقيقية في الخلفية عبر Android AlarmManager وBroadcastReceiver وMediaPlayer لمدة 3 إلى 30 ثانية.
- إعادة جدولة الأجراس بعد إعادة تشغيل الجهاز، تغيير التوقيت أو تحديث التطبيق (ضمن قيود Android).
- نسخ احتياطي JSON وتصدير/مشاركة واستيراد.
- بيانات المطوّر: أ. محمد حيدره — 785068859.

## تعليمات الإنشاء
هذه ملفات المصدر، **وليست APK مبنيًا**. افتح المشروع في بيئة Flutter ثم نفّذ:

```
flutter create --platforms=android --project-name school_bell_v3 .
flutter pub get
flutter build apk --debug
```

**مهم:** قبل تنفيذ `flutter create` احتفظ بنسخة من المجلد لأن الأمر قد يولد ملفات Android الافتراضية. إذا استبدل ملفات Android المرفقة، أعد نسخ ملفات Android الخاصة بهذه الحزمة فوق الملفات المولدة. يُنشئ الأمر أيضًا gradlew وأيقونات التطبيق وملفات Gradle المطلوبة.

إذا كنت تستخدم Klencod IDE، يجب أن يدعم **Flutter** وليس مشروع Kotlin فقط.

## قيود Android
- Android 12+ قد يتطلب السماح بالأجراس/المنبهات الدقيقة من إعدادات التطبيق. يوجد زر داخل الإعدادات لفتح طلب السماح.
- Android 13+ يحتاج إذن الإشعارات؛ عدم السماح قد يمنع الإشعار المرئي.
- بعض الأجهزة تؤخر التنبيهات بسبب توفير الطاقة؛ راجع إعدادات البطارية.
- تشغيل الصوت أثناء إغلاق التطبيق يعتمد على أذونات النظام وعدم إيقاف التطبيق قسرًا.
- **النافذة العائمة ليست مفعلة في هذه النسخة**. لا تدّعي الحزمة تنفيذ overlay.
- الجدولة تحتفظ بأجراس الأسبوع المقبل وتعيد بناءها عند وقوع جرس أو فتح التطبيق/إعادة تشغيل الهاتف. قد تتأثر إذا تجاوز الهاتف أسبوعًا بلا تشغيل للمنبهات.
- لم يتم بناء APK أو اختباره على جهاز فعلي ضمن هذه الجلسة.
